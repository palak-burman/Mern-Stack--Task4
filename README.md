# Mern-Stack--Task4

## Description
This task demonstrates the use of CSS viewport units, box model properties, fonts, and gradient backgrounds.

## Technologies Used
- HTML
- CSS

## Features
- Responsive image display
- Image and button centered on the webpage
- Uses viewport units (`vw` and `vh`)
- Uses CSS Box Model
- Uses `box-sizing: border-box`
- Styled button with gradient background
- Custom font styling

## Files
- `index.html` - Contains the webpage structure
- `style.css` - Contains all CSS styling
- `README.md` - Project information

## Output
The webpage contains an image and a styled "Click Me" button displayed in the center of the page.

## How to Run
1. Open the project folder.
2. Open `index.html` in a web browser.
